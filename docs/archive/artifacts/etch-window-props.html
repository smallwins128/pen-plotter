Etch Window Props
R04 Etch · printed window inserts · ideas, not in the model

Six things a window can be

All black PETG, no acrylic. Every insert screws to the same four holes round each opening, so they swap freely, and each works in the control window too.

1 · Pen garage

Recessed tray with cradles for spare pens, caps out. Three pens per opening. Pens are swapped from the front.

2 · Plot card frame

A printed frame with a slide-in slot behind. Drop in a card the machine drew: a wave study, a spiral, a calibration swatch.

3 · Louvred intake

Angled slats; you can't see in, air still flows. A foam dust filter sits behind.

4 · Carry handle

A deep finger pocket with a rounded lip at the top edge. Lift the box from the front.

5 · Contour relief

A solid black insert with raised topographic contours, like a plot of a hill. Light rakes across the ridges.

6 · Instrument face

Black relief only: a dial with ticks and a needle, a little bar meter. Purely decorative, reads as a machine panel.
